## Pre-publication checklist
- [ ] The manuscript is monolingual and independently localized.
- [ ] All units and learning outcomes are complete.
- [ ] Every closed-ended exercise maps to an answer-key entry.
- [ ] Open activities have criteria and accepted response guidance.
- [ ] Qualified target-language edit is recorded.
- [ ] Pedagogical review and level claims are verified.
- [ ] Rights, attribution and asset permissions are cleared.
- [ ] PDF rendering, accessibility and full-page proof are complete.
- [ ] Final filename, source commit, workflow run and SHA-256 are recorded.
