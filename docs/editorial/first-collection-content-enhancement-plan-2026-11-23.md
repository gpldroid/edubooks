# EduBooks — First collection content enhancement plan

**Prepared:** 2026-11-23  
**Scope:** The six published monolingual PDFs: Language Foundations (EN/FR/ES) and Essential Vocabulary (EN/FR/ES).  
**Distribution:** Free browser preview and full-PDF download on the EduBooks website only.

## Editorial principles

1. Preserve three independent editions per title. Do not translate one manuscript mechanically into the other languages.
2. Keep Language Foundations at a Pre-A1–A1 learning target and Essential Vocabulary at an approximate A1–A2 learning range. These are learning targets, not CEFR certifications.
3. Improve usefulness and practice depth without padding page count or repeating the same exercise.
4. Use natural, level-appropriate examples and identify regional variants when they materially affect usage.
5. Every closed-answer exercise must map to an answer-key entry. Open tasks need clear success criteria and sample responses where useful.
6. Do not invent human reviewer names, sign-offs, accessibility results, citations or source permissions.
7. Preserve the public free-only model and the existing book URLs unless a deliberate versioned release is prepared.

## Book 01 — Language Foundations

The existing ten-unit sequence remains the foundation. Enrich the learning experience rather than adding unrelated topics.

| Unit | Enhancement work |
|---|---|
| 1. Start Here: How Languages Work | Add a baseline self-check, a realistic weekly study planner and a worked example of a 15-minute learning session. |
| 2. Alphabet and Spelling | Add letter-name practice, spelling names/addresses safely with fictional examples, common spelling contrasts and short dictation scripts. |
| 3. First Sounds and Pronunciation | Add mouth/tongue placement cues where appropriate, stress and rhythm practice, minimal-pair awareness and short read-aloud scripts. Avoid implying that spelling predicts pronunciation perfectly. |
| 4. Greetings and Politeness | Add formal/informal choices, time-of-day variations, short dialogue pairs and context notes. |
| 5. Introducing Yourself | Add model introductions at two lengths, question/answer exchanges and privacy-safe fictional profile cards. |
| 6. Numbers, Dates and Time | Add dates, prices, phone-number reading, clock times and regional format cautions. |
| 7. Personal Information and Questions | Add question-word tables, short interview practice and answer frames with fictional data. |
| 8. Classroom and Learning Language | Add clarification, repetition and help-request phrases plus teacher/learner role-play. |
| 9. First Sentences | Add a controlled sentence-building ladder, basic word-order corrections and a short editing checklist. |
| 10. Integrated Beginner Project | Add a staged final task, learner checklist, simple rubric and a model output that does not require private information. |

**Shared appendices to add:** pronunciation and spelling reference, common classroom phrase bank, weekly progress tracker, and a concise cumulative review with a complete answer crosswalk.

## Required unit structure for every revision

- Clear unit-level can-do outcome.
- A short, natural context or dialogue.
- Vocabulary and complete expressions in context.
- A focused language/usage note.
- Practice moving from recognition to controlled use to communication.
- Answer check for every closed-ended item, including accepted alternatives.
- Open task with success criteria and an example where appropriate.
- Short self-check and retrieval/review prompt.

## Production and review sequence

1. Draft the English enhancement for one unit as an editorial prototype; do not rewrite all units at once.
2. Review the prototype for level, usefulness, exercise validity, originality and layout fit.
3. Localize the approved learning design independently into French and Spanish, with language-specific examples.
4. Run automated structure and answer-key checks.
5. Complete publisher-led human language/editorial review and record findings.
6. Regenerate all three language PDFs and five-page samples for the affected title.
7. Inspect page flow, text extraction, links, fonts, preview and full download.
8. Merge a release only when the production checks pass; publish human-review or accessibility statements only when the publisher supplies the completed findings.

## First implementation slice

Start with Book 01, Unit 2 (Alphabet and Spelling) as the prototype because it is a concrete beginner skill with easily testable outcomes. The prototype must include:
- letter-name and spelling practice;
- at least one short dictation script;
- common spelling contrasts and examples;
- a privacy-safe spelling task using fictional names;
- a complete answer key and explicit accepted variants.

After the prototype is reviewed, apply the same editorial pattern to the remaining units. This plan does not claim that any human review has already occurred.
