# Book 02 — first answer-key cross-check

**Date:** 2026-11-22  
**Scope:** Twelve units in each independent English, French and Spanish manuscript.  
**Method:** Compare each guided-practice prompt with its local answer-check entry and check the expected grammatical form and context.

## Findings and corrections

### French — Unité 10

The original prompt was “Aujourd'hui, il fait ____ (beau et lumineux)” while the answer list accepted “beau / ensoleillé”. *Il fait beau* is idiomatic, but *il fait ensoleillé* is not. The prompt now reads “Aujourd'hui, le temps est ____ (beau et lumineux)”, for which both *beau* and *ensoleillé* are natural completions.

### Spanish — Unidad 9

The original prompt “Me duele la ____ (parte del cuerpo)” allowed many possible body parts while the answer key supplied only *cabeza*. The clue now specifies “(cabeza)”, so the expected answer is unambiguous and aligned with the key.
