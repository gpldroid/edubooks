# English Starter A1 — Preview QA

The preview source is intentionally separate from the full manuscript.

Required checks:
- [ ] PDF starts with a title/cover page.
- [ ] Description and learning-target disclaimer are present.
- [ ] Contents list includes all eight units, review test and answer key.
- [ ] Exactly four sample sections are included.
- [ ] Preview is clearly marked as review-only.
- [ ] PDF text extraction is readable and no page is blank.
- [ ] No full-book PDF or commercial download is included.
- [ ] Preview is not copied to \`public/\` until the release owner approves its public use.

The GitHub Actions workflow uploads a review artifact only. It does not publish the PDF or alter the website catalogue.
