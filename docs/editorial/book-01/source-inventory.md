## Extraction and authoring rules

- Create one learner-facing manuscript per language; do not retain three-language comparison tables as the main teaching format.
- Rewrite all instructions, examples, exercises, projects, self-checks and answer keys for the target language.
- Keep language comparison only when it is the explicit learning objective; clearly label the target-language learner instructions.
- Reconcile the answer key with every exercise after rewriting.
- Units 4–10 and the end matter require a full editorial audit; their presence in the source does not establish publication completeness.
