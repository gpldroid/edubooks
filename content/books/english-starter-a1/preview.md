# About this workbook

English Starter A1 is a practical beginner workbook for Arabic-speaking learners. It introduces everyday vocabulary, basic sentence patterns and simple communication tasks through short lessons and guided practice.

The draft contains eight learning units, a review test, an answer key and a progress tracker. The intended study plan is four weeks, with 20–30 minutes of practice each day.

**Learning target:** pre-A1 to A1 (editorial target only; not an official CEFR certification).

# Sample 1 — Hello!

## Key language

| English | Arabic |
|---|---|
| Hello. / Hi. | مرحباً |
| Good morning. | صباح الخير |
| Good afternoon. | مساء الخير (بعد الظهر) |
| Goodbye. / See you. | إلى اللقاء |
| What's your name? | ما اسمك؟ |
| My name is Sara. | اسمي سارة. |
| Nice to meet you. | سعيد بلقائك. |

## Grammar: Subject pronouns and the verb *be*

| Subject | Be | Example |
|---|---|---|
| I | am | I am Ali. |
| You | are | You are kind. |
| He / She / It | is | She is a student. |
| We / They | are | They are friends. |

Contractions: I'm, you're, he's, she's, it's, we're, they're.

## Practice

1. Complete: I ___ Ahmed.
2. Complete: She ___ a teacher.
3. Choose: (They is / They are) happy.
4. Write a greeting for 9:00 a.m.
5. Introduce yourself in two sentences.

# Sample 2 — Personal Information

## Useful words

| English | Arabic |
|---|---|
| first name | الاسم الشخصي |
| surname | اسم العائلة |
| age | العمر |
| country | البلد |
| city | المدينة |
| phone number | رقم الهاتف |
| email | البريد الإلكتروني |
| student | طالب |
| teacher | معلم |

## Grammar: Questions with *be*

- What is your name? — My name is Omar.
- How old are you? — I am 18 years old.
- Where are you from? — I am from Morocco.
- Where do you live? — I live in Tangier.

## Practice

Complete the questions:

1. What ___ your name?
2. Where ___ you from?
3. How old ___ she?
4. Write three sentences about yourself. Use your real information only if you want to.

# Sample 3 — Everyday Objects and This/That

## Vocabulary

| English | Arabic |
|---|---|
| book | كتاب |
| pen | قلم |
| notebook | دفتر |
| phone | هاتف |
| bag | حقيبة |
| table | طاولة |
| chair | كرسي |
| key | مفتاح |
| door | باب |
| window | نافذة |

## Grammar: *a / an* and *this / that*

Use **a** before a consonant sound: *a book*, *a pen*.

Use **an** before a vowel sound: *an apple*, *an orange*.

- This is a book. (near)
- That is a window. (far)
- Is this your phone? Yes, it is. / No, it isn't.

## Practice

Choose *a* or *an*:

1. ___ apple
2. ___ notebook
3. ___ orange
4. ___ umbrella

Write two sentences about objects near you.

# Sample 4 — Daily Routines

## Vocabulary

| English | Arabic |
|---|---|
| wake up | يستيقظ |
| get dressed | يرتدي ملابسه |
| have breakfast | يتناول الفطور |
| go to school | يذهب إلى المدرسة |
| study | يدرس |
| work | يعمل |
| go home | يعود إلى المنزل |
| sleep | ينام |

## Grammar: Present simple

Use the base verb with *I / you / we / they*:

- I study English.
- They work in a school.

Add **-s / -es** with *he / she / it*:

- She studies English.
- He goes to work.

Questions: *Do you study? Does she work?*

Negative: *I don't work. He doesn't work.*

## Practice

1. He (study / studies) English.
2. They (go / goes) to school.
3. ___ you work? (Do / Does)
4. She ___ like coffee. (don't / doesn't)
5. Write four sentences about your day.
